# Ironsworn content pack

The Ironsworn rulebook's moves, assets, oracles, NPCs, truths and rules as structured data. It is the
`@datasworn/ironsworn-classic` 0.0.10 package's `classic.json`, unchanged, and it backs the Ironsworn ruleset
(`dungeon/rules/ironsworn.py`, Milestone 4).
